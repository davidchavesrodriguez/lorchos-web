# GB Lorchos Web Style Guide

This document adapts the official GB Lorchos 2026/2027 visual identity to the website.

The original source is [`GB-Lorchos-style-guide.pdf`](./GB-Lorchos-style-guide.pdf).

## Principles

The visual language should feel:

- editorial
- authentic
- clean
- Galician
- recognisably GB Lorchos
- community-oriented

Consistency is more important than visual complexity.

Use real club photography whenever possible. The people, pitches, mud, Barbanza surroundings, matches and training sessions are part of the identity.

## Colours

- Lorchos Cyan (main color): `#00CDFF`
- Lorchos Orange (secondary color): `#F58A20`
- White (base for light mode, auxiliar for dark mode): `#FFFFFF`
- Auxiliary Dark Blue (base for dark mode, auxiliar for light mode): `#152536`

### Usage

Cyan is the primary identity colour. Use it for key concepts, accents, active states and selected visual elements.

Orange is secondary. Prefer it for practical information, dates, times, scores and important calls to action.

Do not let cyan and orange compete across large surfaces.

Dark blue may be used for strong institutional backgrounds and high-contrast sections.

Do not introduce unrelated brand colours without a functional reason.

## Typography

### Cormorant Garamond

Editorial typeface.

Use for:

- prominent headings
- short expressive statements
- selected introductory text

Avoid using it for small UI text or long functional content.

### Montserrat

Functional typeface.

Use for:

- navigation
- buttons
- labels
- metadata
- scores
- dates and times
- functional headings
- body copy when appropriate

Prefer clear hierarchy over using many weights.

## Photography

Photography should be a primary visual element.

Prefer:

- genuine GB Lorchos and GB Lorchas photography
- movement and human emotion
- recognisable club environments
- images with useful negative space
- natural colour and contrast

Avoid:

- stock photography
- strong artificial filters
- excessive blur
- fake cinematic effects
- effects that compete with the photograph

Image treatment must improve readability, not become the visual subject itself.

## Crests

Use official crest assets only.

Do not:

- distort them
- rotate them arbitrarily
- recolour them
- add shadows
- modify their proportions

Lorchos and Lorchas must receive equivalent visual prominence when content represents both teams.

A monochrome crest may occasionally be used as a subtle background element, but never as gratuitous decoration.

## Layout

Prefer:

- strong photography
- editorial typography
- generous whitespace
- clear alignment
- deliberate asymmetry where useful
- simple separators
- strong visual hierarchy

Avoid:

- generic card grids as the default layout
- excessive rounded corners
- floating UI elements
- glassmorphism
- decorative gradients
- neon/glow effects
- unnecessary shadows
- scroll animations without functional value

The website should not look like a SaaS landing page.

## Motion

Motion must be subtle and functional.

Respect `prefers-reduced-motion`.

Do not add animation libraries unless a concrete requirement justifies them.

## Accessibility

- Maintain sufficient colour contrast.
- Never communicate information using colour alone.
- Provide useful alternative text for meaningful images.
- Ensure keyboard navigation works.
- Maintain visible focus states.
- Design mobile-first and verify layouts on real narrow viewports.

## Content

The primary language is Galician.

Copy should be:

- clear
- concise
- natural
- welcoming
- institutional when appropriate

Avoid generic sports clichés.

The club should be presented primarily through its people, community and identity, not only through sporting results.
